# Cause and effect

A fishbone diagram: one problem on the right, and its possible causes, sorted into six kinds. Use it to find where to look, before choosing what to fix.

#### Make it yours

- Write the problem on the red card: what, where and how much.
- List possible causes under each of the six kinds; rename the kinds to suit.
- Mark the likeliest causes, then check them with data.
