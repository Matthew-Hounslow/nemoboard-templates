# nemoboard templates

Ready-made boards to start a [nemoboard](https://nemoboard.com) project from. Each template is an ordinary nemoboard project: a folder of `.nemo.md` markdown files, with `index.nemo.md` as the top board and a file for each sub-board.

## Using a template

1. Download the template's `.zip` from the list below.
2. On [nemoboard.com](https://nemoboard.com), open the project menu (the project's name, top left) and choose **Import ▸ .zip file…**.
3. Pick the `.zip`. It opens as a new project, named after the template and kept in your browser. Rename the cards and make it yours.

In Chrome or Edge you can also unzip it and choose **Open folder…** to work on the files on disk.
